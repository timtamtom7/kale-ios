# Kale

A supplement and vitamin tracker.

## What it does

- Barcode scanning
- schedules
- AI supplement insights
- family sharing

## Targets

- iOS with Mac companion

## Structure

Key types:

- ``BarcodeService``
- ``AISupplementInsights``
- ``VitaminIntelligenceService``
- ``HealthInsightsService``
- ``SmartReminderService``
- ``FamilyService``

Scans barcodes to identify supplements, which is the part that makes it more than a checklist.

## Status

Apple-platform experiment built to explore what an AI coding agent could produce for a native app. Not actively maintained.
